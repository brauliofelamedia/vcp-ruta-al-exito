# Checklist antes de entregar a Oriana

## Dominio y seguridad

- [ ] Hostname aprobado por Oriana, sin cambios a registros ajenos.
- [ ] HTTPS y certificado válidos, sin advertencias del navegador.
- [ ] Acceso privado real en el sitio y en las cinco descargas PDF.
- [ ] Una visita no autorizada no puede obtener la página ni sus recursos protegidos.
- [ ] No hay tokens, claves API ni credenciales dentro de archivos públicos.
- [ ] Prueba sin VPN desde una red representativa de estudiantes, con resultado documentado.

## Página y navegación

- [ ] Logo, mapa, explorador y tipografías cargan desde el nuevo alojamiento.
- [ ] Las 12 estaciones abren y cierran en la ruta paso a paso.
- [ ] Los números del mapa abren la estación correcta.
- [ ] Anterior, Siguiente y Mi próxima estación funcionan.
- [ ] Ambas vistas se pueden usar en computadora y teléfono, sin texto cortado.
- [ ] Controles accesibles con teclado y texto ampliado.
- [ ] No hay errores de JavaScript ni recursos locales ausentes.

## Sistemas y residencia

- [ ] Definitivo abre `vendecomopro-el-sistema-definitivo-2`.
- [ ] Élite abre `vendecomopro-elite-2`, no el curso de Definitivo.
- [ ] Grabaciones abre `grabaciones-de-zoom` para ambos.
- [ ] Definitivo muestra seis meses y una sesión individual mensual.
- [ ] Élite muestra doce meses y dos sesiones individuales mensuales.
- [ ] Fuera de Estados Unidos muestra prep center previo a la compra, Hushed principal y TalkYou alternativa.
- [ ] Dentro de Estados Unidos muestra preparación en casa y lista de insumos.
- [ ] Pablo no aparece como coach.

## Progreso y recursos

- [ ] Una marca cambia los contadores de tareas y, al terminar una estación, su estado.
- [ ] Las marcas se conservan al recargar en el mismo navegador/origen.
- [ ] Medium y Élite mantienen sus tareas separadas.
- [ ] Reiniciar requiere confirmación y elimina solo las marcas locales.
- [ ] Sigue visible la aclaración de que el progreso no se envía al equipo.
- [ ] Los cinco PDF descargan y abren correctamente.
- [ ] Academia, asesorías y guías externas mantienen sus URL originales.
- [ ] Oriana conoce que el progreso del dominio anterior no se migra automáticamente.

## Cierre

- [ ] Copia de respaldo guardada y procedimiento de actualización documentado.
- [ ] Sitio anterior conservado hasta la aceptación del nuevo.
- [ ] URL final e informe breve enviados a Oriana para aprobación.

Esta lista es para validar el nuevo alojamiento. No significa que las pruebas de red, dominio, privacidad o navegador de producción ya se hayan realizado.
